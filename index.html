04. Agentic AI Series

I'm rebuilding LLM systems from scratch and documenting each step publicly. The goal: understand the raw mechanics before reaching for frameworks. Published on LinkedIn and GitHub.

  • Phase 1

    Bare-Bones Agent Loop

    No frameworks. One file. LLM API + prompt + loop + plain Python functions as tools. What is an agent, really?

    Published
  • Phase 2

    Add Complexity Incrementally

    Web search, live data APIs, multi-turn memory, Gradio UI. Focus on prompting, hallucination control, and structured outputs.

    Published
  • Phase 3

    Separate the Concerns

    Same agent, split into FastAPI backend + React/Vite frontend. Agent logic and architecture are independent decisions.

    Published
  • Phase 4

    Introduce Frameworks

    Rebuild with LangChain, then LangGraph for stateful workflows. Streaming, retries, rate limits, error handling.

    In Progress
  • Phase 5

    Retrieval Layer

    Add RAG, vector DBs, and memory. Retrieval quality, context window management, structured outputs with Pydantic.

    Coming Soon
  • Phase 6 → 7

    Multi-Agent + Multimodal

    Specialized agents that coordinate (planner, researcher, reporter). Eval datasets, accuracy measurement, and MCP.
